# 🔥 FlameGrill — Système de Commande Restaurant

Application web de commande en ligne pour restaurant, avec intégration Telegram.

## ✨ Fonctionnalités

- 🍔 Menu interactif (9 catégories)
- 📲 Notifications Telegram en temps réel
- 🎨 Design thème feu
- 📱 Interface responsive

## 🛠️ Technologies

- Python / Flask
- SQLite
- Telegram Bot API
- HTML / CSS / JavaScript
